# 🎵 PPT 가사 자동 생성 프로그램 (Lyrics PPT Auto-Generator)

본 프로그램은 파워포인트(PPT) 템플릿의 서식을 완벽하게 유지하면서, 찬양이나 행사의 가사를 원하는 위치에 자동으로 삽입해주는 자동화 도구입니다. 복잡한 한글 폰트 유지, 템플릿 마스터 배경 유지, 그리고 데이터베이스(DB)를 통한 세트리스트 관리를 완벽하게 지원합니다.
---

## 📥 0. 다운로드 및 실행 방법 (파이썬 설치 불필요!)

파이썬을 설치할 필요 없이 다운로드 후 바로 더블클릭하여 사용할 수 있는 실행 파일(.exe)을 제공합니다.

1. 본 페이지 우측 상단의 **[Releases]** 항목(또는 아래 링크)을 클릭합니다.
   👉 **[최신 버전 실행 파일(.exe) 다운로드 페이지 바로가기](https://github.com/jtg960528/AutoLyricsPPT/releases)**
2. `Assets` 목록에서 **`main.exe`** 파일(및 템플릿 예시 파일)을 클릭하여 다운로드합니다.
3. 다운로드받은 **`main.exe`** 파일만 더블클릭하면 프로그램이 바로 실행됩니다.

*(※ 윈도우 디펜더 보안 경고창이 뜰 경우: `추가 정보` 클릭 ➡ `실행` 버튼 클릭)*

## ⚠️ 1. PPT 템플릿 준비하기 (가장 중요)

프로그램이 PPT를 완벽하게 복제하기 위해서는 **템플릿 파일이 아래의 규칙에 맞게 제작**되어 있어야 합니다.

1. **배경 이미지 및 디자인은 [슬라이드 마스터]에 넣기**
   * 슬라이드에 직접 이미지를 복사/붙여넣기 하면 프로그램이 새 슬라이드를 만들 때 그림이 날아갑니다.
   * 반드시 상단 메뉴의 `[보기] -> [슬라이드 마스터]`에 들어가서 배경(노란 띠, 캐릭터 등)을 꾸민 뒤 적용해주세요.
2. **텍스트 상자는 위(제목용), 아래(가사용) 최소 2개가 있어야 합니다.**
   * 프로그램은 화면에서 '더 위쪽에 있는 텍스트 박스'를 제목으로, '더 아래쪽에 있는 텍스트 박스'를 가사로 자동 인식합니다.
3. **폰트와 글자 크기 '강제 덮어쓰기' 하기**
   * 파워포인트 기본 테마 서식을 쓰면 파이썬이 폰트를 인식하지 못할 수 있습니다. (특히 '수다공주' 같은 예쁜 한글 폰트)
   * 텍스트 상자 안의 글씨를 **마우스로 모두 드래그(블록 지정)한 뒤, 글꼴과 글자 크기를 다른 것으로 바꿨다가 다시 원래 원하는 폰트/크기로 명시적으로 클릭해서 지정**해 주세요.
   * 프로그램은 이 설정값(XML)을 '도장 찍듯이' 완벽하게 복제합니다.

## 🚀 2. 프로그램 사용 방법

### [1단계] 템플릿 및 설정 지정
* **PPT 템플릿 선택:** 준비한 템플릿 파일(.pptx)을 불러옵니다.
* **기준 슬라이드 번호:** 서식(폰트, 위치)을 복사해 올 원본 슬라이드 번호를 입력합니다.
* **삽입 시작 위치:** 새롭게 생성된 가사 슬라이드들이 기존 PPT의 몇 번째 장부터 끼워질지 숫자로 지정합니다. (기존 슬라이드들은 자연스럽게 뒤로 밀려납니다.)

### [2단계] 노래 가사 입력 (자유로운 슬라이드 분할)
가사 입력창은 **사용자가 작성한 모양 그대로(WYSIWYG)** 화면에 출력되도록 설계되었습니다. 프로그램이 임의로 단어를 자르거나 줄을 나누지 않습니다.

* **엔터 1번 (줄 바꿈):** 같은 슬라이드 안에서 다음 줄로 넘어갑니다.
* **엔터 2번 (빈 줄 생성):** **새로운 슬라이드(다음 장)로 넘어갑니다.**

```text
(입력 예시)
People of GOD People of GOD
너! 하나님의 거룩한 백성이니

크신 하나님 너와 함께하시니
너의 모든 길을 인도하시니
하나님의 백성답게
믿음으로 나아가라
```
*(위와 같이 입력하면 빈 줄을 기준으로 2장의 슬라이드로 나뉘어 생성됩니다.)*

### [3단계] 노래 DB 관리 및 장바구니 시스템
수십~수백 곡을 매번 새로 칠 필요 없이, 나만의 노래 데이터베이스(.json)를 구축할 수 있습니다.

* **목록 불러오기:** 저장된 DB 파일을 열면 **[장바구니 팝업창]**이 열립니다.
  * **실시간 검색:** 띄어쓰기를 무시하고 제목을 즉시 검색합니다.
  * **담기/빼기:** 왼쪽 목록에서 곡을 찾아 '담기'를 누르면 오른쪽 장바구니로 들어갑니다.
  * **DB 수정/삭제:** 왼쪽 목록 아래의 버튼을 이용해 DB 원본의 오타를 수정하거나 영구 삭제할 수 있습니다. (수정 즉시 파일에 반영됨)
* **새 파일로 저장:** 현재 메인 화면에 있는 오늘 행사용 세트리스트를 별도의 파일로 저장합니다.
* **기존 DB에 추가:** 오늘 새로 입력한 신곡들을 나의 '전체 DB' 파일의 맨 밑에 안전하게 병합(누적)시킵니다.

### [4단계] 세트리스트 최종 정렬 및 PPT 생성
* 메인 화면의 리스트박스에서 곡을 선택하고 **[▲ 위로], [▼ 아래로]** 버튼을 눌러 행사 순서에 맞게 순서를 조절합니다.
* 불필요한 곡은 **[선택 삭제]**로 지웁니다. (번호가 자동으로 갱신됩니다.)
* 마지막으로 **[PPT 만들기]** 버튼을 누르고 저장할 위치를 선택하면 마법처럼 PPT가 완성됩니다!

## ❓ FAQ 및 문제 해결

**Q. 가사 글자 크기가 제가 지정한 것보다 작게 나와요!**
A. 템플릿 PPT를 열고 해당 글자를 드래그한 뒤, 폰트 크기를 명시적으로 다시 한 번 클릭(덮어쓰기)하고 저장해 보세요.

**Q. '제목을 추가하려면 클릭하십시오' 같은 기본 글자가 겹쳐서 나와요.**
A. 프로그램이 새 슬라이드를 만들 때 자동으로 방해되는 기본 틀(Placeholder)을 삭제하도록 업데이트되었습니다. 만약 그래도 나온다면 템플릿 슬라이드 마스터에서 불필요한 레이아웃 상자를 지워주세요.

**Q. DB 파일을 불러왔는데 에러가 나요.**
A. 직접 메모장 등으로 `.json` 파일을 열어 수정하다가 쉼표(,) 등을 잘못 지웠을 가능성이 높습니다. 프로그램 내의 [DB 곡 수정] 기능을 이용하는 것이 가장 안전합니다.
